# Inspecciones MLP

PWA de inspecciones de terreno para infraestructura eléctrica de Minera Los Pelambres (MLP), de BBOSCH.
Next.js 16 · Tailwind · Supabase (Postgres, Auth, Storage, RLS) · Vercel.

- **Léalo primero:** `docs/MAESTRO.md` (directorio, estado y faltantes), luego `docs/bitacora/` (`ESTADO.md`: pendientes y decisiones; `REGISTRO.md`: historial de cambios).
- **Reglas de trabajo y comandos:** `CLAUDE.md`.
- **Diseño:** `docs/guias/DESIGN.md` · **Despliegue:** `docs/guias/DEPLOY_VERCEL.md` · **Maestro de TAG:** `docs/guias/EXPORT_MAESTRO.md` · **Licencias:** `docs/guias/LICENCIAS.md`.
- **Cómo correr el proyecto:** `docs/guias/DESARROLLO.md` · **Análisis y datos de apoyo:** `docs/referencia/`.
