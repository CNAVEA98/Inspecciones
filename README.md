# Inspecciones MLP

PWA de inspecciones de terreno para infraestructura eléctrica de Minera Los Pelambres (MLP), de BBOSCH.
Next.js 16 · Tailwind · Supabase (Postgres, Auth, Storage, RLS) · Vercel.

- **Léalo primero:** `docs/MAESTRO.md` (directorio, estado y faltantes), luego `docs/BITACORA.md` (historial, pendientes y decisiones).
- **Reglas de trabajo y comandos:** `CLAUDE.md`.
- **Diseño:** `docs/DESIGN.md` · **Despliegue:** `docs/DEPLOY_VERCEL.md` · **Maestro de TAG:** `docs/EXPORT_MAESTRO.md` · **Licencias:** `docs/LICENCIAS.md`.
- `docs/archivo/`: documentos antiguos, solo de consulta histórica (pueden estar desactualizados).
